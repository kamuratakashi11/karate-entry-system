スマートフォンでPDFにするには

iPhone …「メモ」アプリで新しいメモを作る → カメラのマーク → 「書類をスキャン」 → ページを続けて撮る → 保存 → 共有 → 「ファイルに保存」

Android … Google ドライブアプリの ＋ → 「スキャン」 → ページを続けて撮る → 保存

学校の複合機でスキャンしたPDFでも構いません。 どうしてもPDFにできない場合は、専門部までメールでお送りください。

申込書が2ページになる場合は、1つのPDFにまとめてください （エントリーが22名を超えると2ページになります）。写真（JPG・PNG）は受け付けません。 あとから何度でも出し直せます（いちばん新しいものを提出物として扱います）。
